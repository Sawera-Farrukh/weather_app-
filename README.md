# Weather App 🌤️

A modern Flutter weather application that displays real-time weather data for any city. Built with a clean dark theme and smooth UI.
This Flutter weather app fetches real-time weather data using a secure API key. Simply add your own weather API key 
(such as from OpenWeatherMap) in the project configuration to get accurate current conditions, hourly forecasts, and weekly 
forecasts for any city.

## Features

- 🌡️ Real-time weather data from API
- 🏙️ Search for any city or airport
- 📍 Popular cities quick access
- ⏰ Hourly forecast
- 📅 Weekly forecast
- 🌙 Beautiful dark theme with night sky background
- 📱 Responsive mobile UI
